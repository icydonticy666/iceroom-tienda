## Cómo funciona Payhip (resumen)
- Plan **Free**: sin cuota mensual, **5% comisión** por venta.
- Aloja archivos (hasta 5 GB/archivo en Free) y entrega descargas automáticas.
- Pagos: **Stripe + PayPal** (el dinero cae en tu cuenta; ellos retienen su %).
- Maneja **IVA digital UE** automáticamente.
- Funciones usadas: **License Keys** (plugins), **Online Course** (academia),
  **Digital Download** (packs), **Bundles**, **Cupones**, **Reviews**, **Afiliados**.

### Sobre los videos (R2)
No hace falta migrar videos. Dentro de una lección "Online Course" puedes
**embeber** el video (YouTube/Vimeo unlisted, o tu R2 con signed URL). Payhip
actúa como muro de pago + entrega; el video sigue donde está.

## Checklist de lanzamiento

- [ ] 1. Crear cuenta en payhip.com con nombre de tienda **iceroom**
- [ ] 2. Conectar **Stripe** y **PayPal** (Settings → Payments) — *lo haces tú*
- [ ] 3. Subir logo + favicon + color de acento (Store Design)
- [ ] 4. Pegar `tema.css` en Custom CSS y ajustar `--acento`
- [ ] 5. Crear **3 categorías**: Plugins · Cursos · Sample Packs
- [ ] 6. Subir 1 producto de cada tipo (usar copy de `productos-copy.md`)
- [ ] 7. Activar **License Keys** en los plugins
- [ ] 8. Crear el **iceroom Pro Bundle** (destacado arriba)
- [ ] 9. Activar **Reviews**
- [ ] 10. Crear cupón `LAUNCH25` (-25%, caduca en 7 días)
- [ ] 11. Prueba de compra tú mismo (cupón 100%) para validar el flujo
- [ ] 12. Publicar y compartir el link
- [ ] 13. Footer con aviso: *"Estamos migrando a la nueva plataforma iceroom"*
